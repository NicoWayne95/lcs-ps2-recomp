LCS RECOMP

A static recompilation of Grand Theft Auto: Liberty City Stories (PS2, USA, SLUS-21423) as a native Windows game.

LCS Recomp contains no game files and no game code. The game's code is recompiled on your own PC from your own disc image. You need your own copy of the game.

Grand Theft Auto and all game content are property of Rockstar Games / Take-Two Interactive. LCS Recomp is not affiliated with or endorsed by them.


ORIGIN

PS2Recomp (GPL-3.0)
https://github.com/ran-j/PS2Recomp
The recompiler and the PS2 runtime this project is built on.

GTA: Vice City Stories native PC port (GPL-3.0)
https://github.com/gothamor/gta-vcs-recomp
Used as the reference for this project. Parts of the runtime are derived from it: the world renderer, the HLE world path, the native sound and movie players, the presenter and the runtime changes on top of PS2Recomp.

hctp-recomp (GPL-3.0)
The VU1 recompiler (tools/vu1_recomp.py) derives from it.
